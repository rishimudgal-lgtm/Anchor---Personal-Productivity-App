# My Management Hub

An Android-first personal dashboard for planning assignments, tracking everyday spending, keeping an eye on pantry expiry dates, and recording productivity.

## First version

- **Today** shows tasks due today, tasks completed today, spending this month, and pantry items expiring within three days.
- **Upcoming** keeps past-due tasks visible and groups future tasks into the next seven days and later.
- **Manage** contains the planner, expense list, and pantry inventory.
- **Progress** summarizes tasks completed and focus minutes logged during the current week.
- Data is stored locally on the device. There is no sign-in or cloud sync in this first version.
- Optional local reminders can be enabled for tasks and pantry items. Task reminders are scheduled for 9:00 AM on the due date (or shortly after if that time has passed today); pantry reminders are scheduled for 9:00 AM up to three days before expiry (or shortly after if adding an item expiring today after 9:00 AM).

Focus sessions are logged manually by duration. Expense amounts are stored as numbers; currency selection can be added once the preferred currency is set.

## Run on Android

Install Flutter, Android Studio with the Android SDK, and an Android emulator or device. From this folder, run:

```sh
flutter pub get
flutter run
```

## Project structure

- `lib/main.dart` — app navigation and screens
- `lib/models.dart` — task, expense, pantry, and focus-session data models
- `lib/hub_state.dart` — app state and local persistence
- `lib/reminder_service.dart` — local task and pantry reminder scheduling
- `android/` — Android host project generated by Flutter
